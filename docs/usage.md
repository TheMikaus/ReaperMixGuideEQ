# MixGuideEQ Usage

## Launch

1. Install with install.lua
2. Open Actions list in Reaper
3. Search for MixGuideEQ
4. Run the action

## UI Workflow

1. Choose a track
2. Choose role (vocals, bass, drums, guitar)
3. Adjust Strength %
4. Click Analyze to view guidance
5. Click Apply Auto EQ to insert/update ReaEQ

## Installer Source

- Installer source folder controls where Update looks for install.lua.
- Use Save Source after changing it.
